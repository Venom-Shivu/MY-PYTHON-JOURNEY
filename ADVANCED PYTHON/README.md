## 📌 Overview

This folder covers **advanced, real-world Python concepts** using **Python 3.8+**.  
It focuses on **modern syntax**, **clean coding practices**, **robust error handling**,  
**functional programming**, **environment management**, and **basic backend development**.

⚠️ Not beginner material.

## 📘 [Chapter 12: Advanced Python 1](Chapter_12_(Advanced_Python_1))  
**Focus:** Language features, type safety, execution flow, and Pythonic patterns.

- Walrus operator (`:=`), dictionary merge (`|`, `|=`)
- Structural pattern matching (`match-case`)
- Type hints (basic & advanced)
- Exception handling & custom exceptions
- `if __name__ == "__main__"`, `global`
- Enumerate & list comprehensions

---

## 📘 [Chapter 13: Advanced Python 2](Chapter_13_(Advanced_Python_2))  
**Focus:** Functional programming, tooling, and backend basics.

- Virtual environments (`venv`) & `pip`
- Lambda functions
- `map`, `filter`, `reduce`
- String & collection optimization
- Flask basics (routes & server)
