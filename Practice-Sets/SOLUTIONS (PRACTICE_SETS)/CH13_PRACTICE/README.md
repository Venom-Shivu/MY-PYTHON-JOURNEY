## Overview
This practice set focuses on **modern Python development workflows and functional programming concepts**.  
It covers the essential tools for managing project dependencies (Virtual Environments) and introduces powerful functional tools (`lambda`, `map`, `filter`, `reduce`), culminating in a real-world web application example using **Flask**.

## Difficulty
**Medium**

## Concepts Covered
- Virtual Environments (`venv`) & Package Management (`pip`)
- Lambda Functions (Anonymous functions)
- `map()`, `filter()`, and `reduce()`
- Advanced String Formatting
- Introduction to Web Frameworks (Flask)

## Practice Problems
1. Setting up and activating a Virtual Environment
2. Advanced string formatting for student details
3. Vertical string representation of lists using `join()`
4. Filtering numbers divisible by 5 using `filter()`
5. Finding the maximum number in a list using `reduce()`
6. Managing dependencies using `pip freeze`
7. Building a basic web server with routes using **Flask**

## Guidelines
- Use Virtual Environments for project isolation
- Prefer list comprehensions or functional maps/filters where appropriate
- Ensure web server code is modular and handles routes correctly
- Follow standard naming conventions
